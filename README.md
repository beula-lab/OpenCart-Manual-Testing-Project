# 🛒 OpenCart Manual Testing Project

## 📌 Project Overview
This repository contains a complete manual testing project for the OpenCart e-commerce application. The project demonstrates real-time QA activities including test planning, test case design, bug reporting, RTM preparation, and test execution documentation.

The objective of this project is to validate the functionality, usability, and reliability of the OpenCart Login Module using manual testing techniques.

## 🌐 Application Under Test

- Application Name: OpenCart
- Application Type: E-Commerce Web Application
- Testing Type: Manual Testing
- Environment: Windows 11 / Chrome Browser

  ## 🧪 Modules Tested

- Login Module
- Registration Module
- Product Search
- Shopping Cart
- Checkout Process
- Logout Functionality
